# Simulador Integral de Evaluación Financiera Sectorial

Proyecto independiente del Simulador de Economía Municipal V1.0.

Base: evaluación financiera de proyectos de inversión, con VAN, TIR, TIRM, B/C, ROI, ROE, Payback, DSCR, escenarios, sensibilidad, CIIU y contexto macroeconómico.
